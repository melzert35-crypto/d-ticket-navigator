
# D-Ticket Navigator

Android-first Reiseplaner für Reisen mit dem Deutschlandticket.

## Projektstatus

Aktueller Entwicklungsstand: Grundgerüst

## Entwicklungsregeln

- Funktionierende Stände werden als Referenz gesichert.
- Keine Regressionen.
- Änderungen werden schrittweise getestet.
- GTFS/DELFI ist die Grundlage für die Fahrplandaten.
- T001–T019 sind die definierten Regressionstests.

## Geplante Datenquellen

- GTFS Regionalverkehr Deutschland
- GTFS ÖPNV Deutschland
- später GTFS-Realtime
- geplante Störungen der Verkehrsunternehmen

## Erste Teststrecke

T001: Hamm → Reichenbach

## Weitere Kernbereiche

- Deutschlandticket-Regeln
- SEV
- Umstiege
- Zugteilung / RB85
- Umfahrungen 50 / 100 / 150 km
